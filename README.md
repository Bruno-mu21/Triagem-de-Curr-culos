O RecruitAI é uma plataforma web para triagem e análise automatizada de currículos de candidatos que utiliza modelos de Inteligência Artificial do Google Gemini. A aplicação extrai o texto de arquivos PDF localmente no próprio navegador por meio da biblioteca PDF.js e permite que o recrutador configure os detalhes da vaga, separando os critérios entre Requisitos Obrigatórios (eliminatórios) e Requisitos Desejáveis (classificatórios). Com base nessas definições, a IA avalia os perfis e gera um JSON estruturado calculando uma nota de adequação (Match Score de 0 a 100%) para cada participante. Os resultados são exibidos em um painel interativo com estatísticas gerais, ranking filtrável por nível de senioridade e nota, um painel lateral (drawer) com o parecer técnico detalhado dos pontos fortes e critérios cumpridos/ausentes, uma ferramenta para comparar até três candidatos lado a lado em uma tabela, além de recursos adicionais como gerador de prompts estruturados copiáveis e dados de demonstração para testes.
